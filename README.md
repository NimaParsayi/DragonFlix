# دراگون‌فلیکس — رزرو آنلاین صندلی سینما

- **بک‌اند**: ASP.NET Core (net10.0) + EF Core (SQLite) + JWT — پوشهٔ `backend/DragonFlix.Api`
- **فرانت‌اند**: Vue 3 + Vite + Vue Router، تم آبی، راست‌به‌چپ — پوشهٔ `frontend`

## اجرا

```bash
# ترمینال ۱ (API روی http://localhost:5080؛ دیتابیس و داده‌های نمونه خودکار ساخته می‌شود)
cd backend/DragonFlix.Api && dotnet run --no-launch-profile --urls http://localhost:5080

# ترمینال ۲ (سایت روی http://localhost:5173؛ /api به بک‌اند پروکسی می‌شود)
cd frontend && npm install && npm run dev
```

ادمین نمونه: `admin@dragonflix.test` / `Admin123!` (قابل تغییر در `appsettings.json` بخش `Seed`؛ قبل از انتشار حتماً `Jwt:Key` را عوض کنید).

## انتشار روی سرور (Docker + GitHub Actions)
راهنمای کامل: [`DEPLOY.md`](DEPLOY.md). خلاصه: `cp .env.example .env` ← پر کردن ← `docker compose up -d --build`؛ و برای دیپلوی خودکار با هر push روی `main` سکرت‌های SSH را در گیت‌هاب بگذار.

## مدل داده
`Cinema → Hall → SeatRow` (هر ردیف: نام، تعداد صندلی، قیمت، فاصلهٔ ابتدا، محل راهروها)،
`Movie`، `Showtime` (فیلم + سالن + زمان + ضریب قیمت)، `Booking → BookedSeat`.
قیمت نهایی هر صندلی = قیمت ردیف × ضریب قیمت سانس. ایندکس یکتا روی (سانس، ردیف، شماره) جلوی رزرو دوبارهٔ یک صندلی را می‌گیرد.

## قابلیت‌های ادمین (`/admin`)
- مدیریت سینماها و سالن‌ها
- **طراح چینش**: افزودن/حذف/جابه‌جایی/کپی ردیف، تعیین قیمت هر ردیف، فاصلهٔ ابتدای ردیف، راهرو با کلیک بین صندلی‌ها و پیش‌نمایش زنده
- مدیریت فیلم‌ها و سانس‌ها (با جلوگیری از تداخل سانس‌ها در یک سالن و ثبت تکراری چندروزه)
- ردیف یا سانسی که صندلی رزروشده دارد قابل حذف نیست و تعداد صندلی ردیف رزروشده زیر بالاترین شمارهٔ رزرو نمی‌رود.

## TMDB و تصاویر فیلم‌ها (اختیاری)
در «فیلم‌ها ← فیلم جدید» می‌توان نام فیلم را (فارسی یا انگلیسی) در TMDB جست‌وجو کرد؛ عنوان و خلاصهٔ فارسی، ژانر، مدت، سال، کاور و بک‌دراپ خودکار پر می‌شوند.

- برای فعال‌سازی، کلید API رایگان TMDB را بگذارید (کلید v3 یا Read Access Token). **کلید را در گیت نگذارید**:
  ```bash
  cd backend/DragonFlix.Api && dotnet user-secrets init && dotnet user-secrets set "Tmdb:ApiKey" "<KEY>"
  ```
  (یا متغیر محیطی `Tmdb__ApiKey`). اگر TMDB از سرور شما مستقیم در دسترس نیست، آدرس یک پروکسی/آینه را در `Tmdb:BaseUrl` و `Tmdb:ImageBaseUrl` بگذارید.
- **بدون TMDB هم همه‌چیز کار می‌کند:** اگر کلید نباشد یا TMDB در دسترس نباشد، فقط یک پیام نشان داده می‌شود و کاور و بک‌دراپ را می‌توان با آپلود فایل (JPG/PNG/WEBP) یا آدرس تصویر دستی گذاشت.
- تصاویر TMDB و فایل‌های آپلودی روی خود سرور (`wwwroot/uploads/movies`) ذخیره می‌شوند و **با حذف فیلم یا جایگزینی تصویر، فایلشان هم پاک می‌شود** (آدرس‌های بیرونی دست‌نخورده می‌مانند).
- این محصول از API سایت TMDB استفاده می‌کند ولی توسط TMDB تأیید یا پشتیبانی نشده است.

## ربات و مینی‌اپ تلگرام
خروجی پروژه یک **مینی‌اپ تلگرام** است: ورود فقط با نشست خود تلگرام انجام می‌شود (امضای `initData` با توکن ربات بررسی می‌شود) و ورود با ایمیل/رمز به‌طور پیش‌فرض غیرفعال است (`Auth:AllowPassword`).

- **توکن ربات** را در `backend/DragonFlix.Api/appsettings.Local.json` (خارج از گیت) بگذارید: `{ "Telegram": { "BotToken": "..." } }` یا متغیر محیطی `Telegram__BotToken`.
- **آدرس HTTPS** لازم است (تلگرام مینی‌اپ را فقط با HTTPS باز می‌کند). برای تست: `ngrok http 5173`، سپس آدرس را در پنل مدیریت ← «پرداخت و ربات» ثبت کنید تا دکمهٔ منوی ربات ساخته شود.
- **ادمین‌شدن:** هنگام اجرا اگر ادمینِ تلگرامی نباشد، لینک یک‌بارمصرف `https://t.me/<ربات>?start=admin_<کد>` در لاگ چاپ می‌شود؛ اولین نفری که بازش کند ادمین می‌شود. ادمین بعدی را از پنل با «ساخت لینک دعوت» اضافه کنید.
- **پرداخت کارت‌به‌کارت:** شمارهٔ کارت را در پنل ثبت کنید. کاربر صندلی را رزرو می‌کند (تا پایان مهلت اشغال می‌ماند)، واریز و رسید را ثبت می‌کند، مدیر از پنل یا با دکمه‌های داخل تلگرام تأیید/رد می‌کند و بلیت QRدار برای کاربر ارسال می‌شود.
- **اعلان‌ها:** ضروری (پرداخت، بلیت، تغییر سانس) همیشه ارسال می‌شود؛ دلخواه (یادآوری سانس، اکران جدید، سانس جدید فیلم‌های دنبال‌شده، تخفیف) را کاربر در «حساب من» یا با /settings در ربات روشن/خاموش می‌کند.
- رسیدهای پرداخت در `App_Data/receipts` (خصوصی) ذخیره می‌شوند و فقط با دسترسی صاحب رزرو یا ادمین خوانده می‌شوند.
